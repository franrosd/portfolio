# Fransiska Rosalina Dewi — Data Analytics Portfolio

A starter portfolio website using HTML, CSS and JavaScript.

## Preview locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Replace the profile placeholder in `assets/images/` with your own photo.
4. Update LinkedIn, GitHub and email links in `index.html`.

## Files
- `index.html` — homepage content
- `style.css` — colours, typography, layout and responsive styling
- `script.js` — mobile navigation interaction
- `assets/images/` — profile and project images
- `projects/` — six individual project case-study pages, based on the uploaded portfolio presentation

## Project links
The six project cards currently link to the Google Slides pages and slide anchors supplied by Fransiska.
